# User Stories

## Sign Up
- The crafter wants to be able to sign up to an application to store my yarn data to keep track of my yarn more efficiently. 

## Sign in 
- The user wants to be able to sign in and access my secured yarn data.

## Find yarn description
- The user want to be able to find the description of my yarn, weight and hook size so I don't have to keep the labels the yarn comes with.

## Find more yarn
- The user wants to be able to find where I purchased this yarn from if I need more. 

## Find projects
- The user wants to be able to find patterns with the yarn I have on hand. 

## Completed projects
- The user wants to be able to enter my completed projects.

## Log projects
- The user wants to enter the project information I'm working on to come back and restart at a later date to know which hook to use and where to buy more yarn.

## Enter yarn
- User wants to enter yarn into the yarn database to keep database up to date.

## Update Yarn
- User wants to update yarn as they have used some or bought more to keep database up to date.

## Remove yarn
- User wants to delete yarn as they have used it to keep database up to date.

## Update Password
- User wants to be able to update password to protect yarn information.
